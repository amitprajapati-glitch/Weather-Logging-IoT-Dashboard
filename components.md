# Hardware Components

| Component | Purpose |
| ESP8266 NodeMCU | Main microcontroller and Wi-Fi connectivity |
| DHT22 | Measures temperature and humidity |
| BMP280 | Measures atmospheric pressure |
| OLED Display | Displays sensor readings |
| Push Button | Controls system ON/OFF |
| Buzzer | Provides ON/OFF sound alerts |
| Blue LED | Indicates system status |

## Communication
- I2C communication for the OLED display and BMP280 sensor, where applicable.
- Wi-Fi communication for sending data to ThingSpeak.
