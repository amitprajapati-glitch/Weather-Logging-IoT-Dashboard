# Weather-Logging-IoT-Dashboard
A project that monitors environmental conditions using sensors and sends the collected data to an online dashboard.
Components Used
- ESP8266 NodeMCU
- DHT22 temperature and humidity sensor
- BMP280 pressure sensor
- OLED display
- Buzzer and push button
Features
- Measures temperature, humidity, and atmospheric pressure.
- Displays readings on an OLED screen.
- Sends data to ThingSpeak.
- Supports system ON/OFF control with buzzer alerts.
My Contribution
I worked on connecting the electronic components, writing and testing the Arduino code, displaying sensor readings, and integrating the system with ThingSpeak.
Technologies
Arduino IDE, C++, ESP8266, IoT, ThingSpeak.
