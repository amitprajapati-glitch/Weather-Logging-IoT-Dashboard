Testing and Learnings

Project
Weather Logging & IoT Dashboard using ESP8266 NodeMCU

Testing Performed
- Tested the DHT22 sensor for temperature and humidity readings.
- Tested the BMP280 sensor for temperature and atmospheric pressure readings.
- Checked the OLED display using I2C communication.
- Tested sensor data transmission to the ThingSpeak cloud platform.
- Tested the system ON/OFF button and buzzer alerts.

Technical Challenges
During development, I worked on sensor interfacing, hardware integration, and Arduino code debugging.

Key Learnings
- Connecting and interfacing multiple sensors with a microcontroller.
- Reading sensor data and displaying it on an OLED.
- Sending sensor readings to an IoT cloud platform.
- Debugging embedded code and checking hardware connections.
- Integrating hardware and software into one system.

Future Improvements
- Add a clear circuit diagram and wiring documentation.
- Improve error handling for sensor and Wi-Fi failures.
- Add more environmental monitoring features.
- Improve the dashboard and data visualization.
